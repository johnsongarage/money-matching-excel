# money-matching-excel — 배달 정산 맞추기 (데모)

배달 주문 한 건마다 **얼마가 빠지고 통장에 얼마가 들어왔는지** 한 화면에 보여 주는 최소 데모입니다.
사장님께 휴대폰으로 보여 드리고 "이게 맞추시는 그거 맞아요? 뭐가 빠졌어요?"를 묻기 위해 만들었습니다.

- 맨 위 요약: 이번 주 배달 판매액 / 통장 입금액 / 1만 원당 입금액
- 항목별 합계: 배달비·중개 수수료·결제 수수료·부가세·할인 부담·광고비 — 어디로 돈이 새는지
- 주문 건별 표: 줄을 누르면 빠진 돈 내역, 예정액·실입금·예정일·실제 입금일
- 예정보다 덜 들어온 주문(빨강), 입금일이 밀린 주문(노랑) 표시
- **리스트 / 달력** 전환: 달력에서는 한 칸에 그날 판 금액(회색)과 통장에 들어온 돈(초록)을 같이 보여 주고, 덜 들어온 날·늦게 들어온 날·들어와야 했는데 안 온 날을 표시. 날짜를 누르면 그날 들어온 돈이 어느 날 판 주문인지 나옴. 주소 끝에 `#calendar`를 붙이면 달력부터 열림

## 디자인 두 가지
위쪽 **디자인** 콤보 박스로 바꿔 볼 수 있습니다. 데이터는 `data.js` 하나를 같이 써서 두 화면의 숫자가 같습니다.

- `index.html` — 기본(카드형): 요약 한 줄, 빠진 돈 막대, 리스트/달력
- `dashboard.html` — 대시보드형: 왼쪽 메뉴, 큰 숫자 카드 2개(통장 입금·빠진 돈), 월 달력(입금 누락·덜 들어옴·늦게 입금 표시, 날짜 누르면 그날 정산만), 구역별 정산 표(확인 필요 / 늦게 들어옴 / 정상 입금)

## 내 파일로 맞추기 (`upload.html`)
배달앱 정산서 엑셀(앱마다)과 통장 거래내역 엑셀을 올리면, **정산 묶음(같은 앱·같은 정산예정일) ↔ 통장 입금**을 맞춰 봅니다.

- 파일은 브라우저 안에서만 읽고 어디로도 보내지 않습니다 (서버 없음, 저장 안 함).
- 칸 이름이 앱마다 달라도 별칭으로 자동으로 맞추고, 틀리면 콤보 박스로 고칩니다. 은행 엑셀 위쪽 제목 줄은 자동으로 건너뜁니다.
- 통장 적요에 배달앱 이름(또는 직접 적은 이름)이 있는 입금을 그 앱 정산으로 봅니다.
- 결과: 정상 / 덜 들어옴 / 늦게 들어옴(7일 안 같은 금액) / 안 들어옴 / 입금 예정, 묶음을 누르면 주문별 빠진 돈. 결과 엑셀로 받기.
- **가짜 정산서**(A·B·C앱, 칸 이름·부호가 서로 다름)와 가짜 통장 내역을 받거나 바로 넣어 볼 수 있습니다. 실제 배달앱 양식이 아니라 "양식이 제각각"인 상황을 흉내 낸 것입니다.
- 엑셀 읽기는 SheetJS(xlsx 0.18.5, cdnjs)를 씁니다.

## 참고 문서
세 화면 위쪽 **참고 문서** 콤보 박스에서 고르면 그 문서로 이동합니다 (목록은 `refs.js`). 로그인 없이 열리는 공개용 HTML 사본입니다.

- `docs/money-map.html` 가맹점 돈길 지도 — 들어오는 돈·나가는 돈을 눌러 보는 지도
- `docs/money-flow.html` 가맹점 돈의 흐름 — 항목별 설명 · 안 맞는 이유 · 다음 질문

원본은 Claude 문서이고, 공개 저장소라 가게·브랜드 이름은 일반 표현으로 바꿨습니다. 원본을 고치면 사본도 손으로 맞춰야 합니다.

## 보는 법
`index.html`을 브라우저로 열면 됩니다 (빌드·서버 없음, `data.js`가 같은 폴더에 있어야 함).

- **웹(넓은 화면, 960px 이상)**: 주문 표에 빠진 돈을 항목별 칸으로 모두 펼쳐 보여 줍니다. 합계 줄 포함.
- **앱(휴대폰)**: 같은 데이터를 추려서 판매·빠진 돈·통장 세 칸만 보여 주고, 줄을 누르면 자세히 나옵니다.

방향: 데이터가 복잡해질 것으로 보여 **웹에서 다 펼쳐 보고, 앱에는 추린 것만** 담습니다.

## 주의
**모든 데이터는 지어낸 예시입니다.** 수수료율·배달비도 설명을 위한 예시이며 실제 배달앱 요율이 아닙니다.
이 저장소는 공개 저장소이므로 실제 매장 데이터는 올리지 않습니다.
