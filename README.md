# money-matching-excel — 배달 정산 맞추기 (데모)

배달 주문 한 건마다 **얼마가 빠지고 통장에 얼마가 들어왔는지** 한 화면에 보여 주는 최소 데모입니다.
사장님께 휴대폰으로 보여 드리고 "이게 맞추시는 그거 맞아요? 뭐가 빠졌어요?"를 묻기 위해 만들었습니다.

- 맨 위 요약: 이번 주 배달 판매액 / 통장 입금액 / 1만 원당 입금액
- 항목별 합계: 배달비·중개 수수료·결제 수수료·부가세·할인 부담·광고비 — 어디로 돈이 새는지
- 주문 건별 표: 줄을 누르면 빠진 돈 내역, 예정액·실입금·예정일·실제 입금일
- 예정보다 덜 들어온 주문(빨강), 입금일이 밀린 주문(노랑) 표시
- **리스트 / 달력** 전환: 달력에서는 한 칸에 그날 판 금액(회색)과 통장에 들어온 돈(초록)을 같이 보여 주고, 덜 들어온 날·늦게 들어온 날·들어와야 했는데 안 온 날을 표시. 날짜를 누르면 그날 들어온 돈이 어느 날 판 주문인지 나옴. 주소 끝에 `#calendar`를 붙이면 달력부터 열림

## 보는 법
`index.html`을 브라우저로 열면 됩니다 (빌드·서버 없음).

- **웹(넓은 화면, 960px 이상)**: 주문 표에 빠진 돈을 항목별 칸으로 모두 펼쳐 보여 줍니다. 합계 줄 포함.
- **앱(휴대폰)**: 같은 데이터를 추려서 판매·빠진 돈·통장 세 칸만 보여 주고, 줄을 누르면 자세히 나옵니다.

방향: 데이터가 복잡해질 것으로 보여 **웹에서 다 펼쳐 보고, 앱에는 추린 것만** 담습니다.

## 주의
**모든 데이터는 지어낸 예시입니다.** 수수료율·배달비도 설명을 위한 예시이며 실제 배달앱 요율이 아닙니다.
이 저장소는 공개 저장소이므로 실제 매장 데이터는 올리지 않습니다.
